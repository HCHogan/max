### v1 scope

Decided 2026-10-28: everything already designed in detail goes into v1, and nothing is postponed merely to keep v1 small. The bottom line is that the complexity of the critical parts, such as the core and concurrent scheduling, must stay under control.

Included:

- Platform: QQ, through Tencent's official bot API (switched from NapCat on 2026-10-28; see [The official QQ bot](../design/qq.md#the-official-qq-bot-1)). Matrix is not implemented for now (decided 2026-10-29); see [Matrix](../decisions/2026-10-29-matrix-deferred.md#matrix).
- Triggering: every inbound message passes through [Intent](../design/intent.md#intent-1). Mentions (@) and replies to Max are its rules; all other messages are judged by a small model (made part of v1 on 2026-10-27; changed on 2026-10-28 so that every message passes through it). Private chats trigger according to an allowlist. Commands are not triggers: the conversation actor handles them itself. See step 2 of [Processing flow](../design/actor.md#processing-flow).
- The canonical ledger: inbound and outbound messages are both persisted to Postgres.
- The conversation actor, a single core instance, input delivery, streaming replies, cancellation (`/kill`) and a short reply on failure.
- LLM: two protocols, Responses and Chat Completions.
- A self-written agent loop with tools (decided 2026-10-27): pure codemode plus one `shell` tool, both running in the group VM; see [Tools and codemode](../design/tools.md#tools-and-codemode-1). v1 therefore also includes the VM sandbox and max's service to it. The first Max tool exposed is `context_read`, which reads full text (merged with `context_search` into `history` on 2026-10-30); see [Follow-up input](../design/context.md#follow-up-input). Which other tools to expose is **TBD**.
- Context projection: the raw tail and the volatile block; see [Context projection](../design/context.md#context-projection-1). The historian and summaries were added to v1 on 2026-10-28, removed on 2026-10-30, restored that same evening as a per-group switch, and removed again on 2026-11-02 once the comparison was complete; see [Summaries](../design/context.md#summaries).
- Restarts: a running turn is given a grace period; when it expires, the turn is interrupted and a one-sentence reply is sent (changed 2026-10-29; previously the turn was suspended and resumed after the restart); see [Restarts](../design/actor.md#restarts).
- Configuration, logging and graceful shutdown.

Not included, but all required before go-live: mirroring, the browser, memory and recall, background agents, automations, media and admin.
